Changelog
=========

v1.1.0 2026-10-14
-----------------

### Features

* Support webdav clients.
* Serve all files in user home (except hidden files and dirs).
* Add offline mode (--offline flag) - prevent downloading empty tiddlywiki from website.
* File-based backups are now created in each directory.

### Fixes

* Sanitize request URL.
* Create wikis dir if not exists.
* Fix various problems and improve logging.
* Fix missing favicon.
* Improve error messages presented to user.
* Fix CORS and others security headers.


### Other

* Updated dependencies
* Code refactoring
